## 🛠️ Using Vibe-Scholar Basics

Once open, here are some first steps for a smooth start:

### Create a New Project

- Click **New Project** on the main screen.  
- Enter a name for your research project.  
- Add a short description if you want.  
- Save it to begin adding notes and data.

### Add Notes and Files

- Inside your project, choose **Add Note** to write text.  
- Use the **Attach File** option to bring in PDFs, images, or documents.  
- Notes and files stay on your PC for privacy.

### Apply Vibe Coding

- Select any note or data piece.  
- Assign vibe codes—these are labels to group and sort your data easily.  
- Customize your codes to match your research method.

### Track Progress

- Use the dashboard view to check what you completed.  
- Mark tasks or notes as done.  
- Visual charts update automatically to show status.
